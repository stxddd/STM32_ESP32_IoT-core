# ESP32 Telemetry Frontend

This app renders live charts for the ESP32 telemetry endpoints:

- `GET /api/telemetry`
- `GET /api/t`
- `GET /api/h`
- `GET /api/p`
- `GET /api/l`
- `GET /api/aq`

For local development, set the device base URL before starting Vite:

```bash
VITE_API_BASE_URL=http://192.168.1.50:8000
```

Vite now binds to `0.0.0.0`, so the app is reachable from other devices on the network.

Then run `npm run dev` or `npm run build` as usual.

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
