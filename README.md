# STM32 & ESP32 IoT Core 

Ядро для IoT с STM32 как головным устройством, передающим по UART на ESP32 эмуляцию (на текуший момент) телеметрии дома, красиво отображаемую фронтендом.

## Структура репозитория

- `ESP32_WEBSERVER/` — прошивка ESP32 с веб-интерфейсом и API для работы с данными, включающая серверную часть.
- `frontend/` — клиентская часть (Vite + React + TypeScript) для управления и отображения данных из ESP32.
- `STM32_UART_DATA_EMUL/` — проект для STM32, эмулирующий передачу данных по UART.
